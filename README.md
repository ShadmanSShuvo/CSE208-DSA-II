# CSE208: Data Structures and Algorithms II
## BUET CSE L2-T1

This repository contains solutions for the CSE208 course offered at Bangladesh University of Engineering and Technology (BUET), specifically for the Computer Science and Engineering department, Level 2 Term 1.

## Course Overview
CSE208 covers advanced data structures and algorithms including:
- **Graph Algorithms**: Single-Source Shortest Path (SSSP), All-Pairs Shortest Path (APSP)
- **Minimum Spanning Trees (MST)**
- **Flow Networks and Maximum Flow**
- **Hash Tables and Hashing Techniques**
- **Binary Search Trees (BST)**

## Folder Descriptions

### Offlines
Contains solutions for offline assignments covering different DSA topics.

### Onlines
Contains solutions for online/practical problems covering graph algorithms and advanced data structures.

## Topics Covered

- **SSSP (Single-Source Shortest Path)**: Algorithms like Dijkstra's and Bellman-Ford
- **APSP (All-Pairs Shortest Path)**: Floyd-Warshall algorithm
- **MST (Minimum Spanning Trees)**: Kruskal's and Prim's algorithms
- **Flow Networks**: Maximum flow algorithms - Ford Fulkerson, Edmonds Karp
- **Hashing**: Hash table implementations and collision handling
- **BST (Binary Search Trees)**: Self-balancing (AVL, RBT) and standard BST operations
